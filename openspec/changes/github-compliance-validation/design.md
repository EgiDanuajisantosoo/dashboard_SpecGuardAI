## Context

The current system has a basic webhook integration that triggers an audit, but it relies on an external AI service which is slated for replacement with direct OpenAI integration within Laravel. The `compliance` view is currently showing static/mock data for the flowchart and lacks the logic to reflect real-time audit results on the Mermaid diagram nodes.

## Goals / Non-Goals

**Goals:**
- Replace the external AI service call in `ProcessAuditJob` with a direct OpenAI implementation.
- Implement a comparison logic where the AI evaluates code diffs against the PRD (`prd_content`) and the Mermaid spec (`spec_content`).
- The AI should output a JSON object containing:
    - Compliance score.
    - Status (complete, partial, failed).
    - `node_status`: A map of Mermaid node IDs/labels to compliance status (true/false).
    - `missing_requirements`: A list of what's missing.
- Update the `compliance.blade.php` view to:
    - Display the Mermaid diagram from `project->spec_content`.
    - Apply colors (Green/Red) to nodes based on the `node_status` in the latest audit.
    - Show audit insights and missing requirements.

**Non-Goals:**
- Automated code fixing or PR suggestions.
- Supporting other version control systems besides GitHub for now.

## Decisions

### 1. Direct OpenAI Integration in Job
Instead of calling a FastAPI service, `ProcessAuditJob` will use `\OpenAI\Laravel\Facades\OpenAI` to perform the audit. This reduces infrastructure complexity and centralizes logic in Laravel.

### 2. Node Mapping via AI
The AI will be tasked with identifying which parts of the Mermaid flowchart (provided in the prompt) are implemented in the code diff. It will return a mapping that the frontend can use to apply CSS styles to the SVG elements generated by Mermaid.

### 3. Frontend Node Coloring
Since Mermaid renders SVG on the client side, we will use a JavaScript snippet in `compliance.blade.php` that waits for the Mermaid diagram to load and then searches for node labels matching the AI's `node_status` keys to apply fill colors.

## Risks / Trade-offs

- **Risk**: AI might fail to map code diffs accurately to Mermaid node labels if labels are ambiguous.
- **Mitigation**: Ensure the system prompt for PRD-to-Mermaid generation uses clear, unique labels, and the audit prompt is instructed to match those labels exactly.
- **Risk**: Mermaid SVG structure can change between versions.
- **Mitigation**: Use a robust selector for nodes (e.g., searching for text elements within `.node` classes).
